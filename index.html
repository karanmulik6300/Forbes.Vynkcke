About this project

Fuel & Boiler Performance Simulation

This website presents the interactive calculation model contained in the supplied Forbes Vyncke simulation. It lets the user change fuel and boiler parameters and immediately see their effect on as-received GCV, NCV, steam generation, fuel requirement and combustible matter.

01

Fuel Quality

Compare Indonesian Coal, Groundnut Briquette, Rice Husk and Mustard Briquette, or enter a custom fuel.

02

NCV Calculation

NCV is calculated from the simulation's as-received GCV, moisture and hydrogen relationship.

03

Boiler Output

Use efficiency and enthalpy inputs to calculate steam generation per tonne of fuel and the fuel requirement for a target capacity.

Model Parameters

The supplied simulation includes Dry GCV, Moisture, Fuel Ash, Hydrogen, Boiler Efficiency, Steam Enthalpy, Feedwater Enthalpy and Target Boiler Capacity. It also provides boiler-capacity comparison, moisture sensitivity and live step-by-step calculations.

Navigation

Use Simulation for calculations, Analysis for a short site assessment, and Customer Summary for the final customer-ready results.
